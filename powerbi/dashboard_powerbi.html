Catálogo de Medidas DAX del Modelo

Total Accidentes

Total Accidentes = COUNTROWS(Accidents)

Cuenta cada registro único respetando los filtros de estado, ciudad, clima, fecha y severidad.

Accidentes FinDeSemana

Accidentes FinDeSemana =
CALCULATE(
    [Total Accidentes],
    WEEKDAY(Accidents[Start_Time], 2) IN {6, 7}
)

Aísla los siniestros ocurridos en sábado (6) y domingo (7) para comparar movilidad recreativa frente a laboral.

Accidentes YTD

Accidentes YTD =
TOTALYTD(
    [Total Accidentes],
    Dim_Calendario[Date]
)

Acumula los eventos desde el 1 de enero hasta la última fecha del contexto anual activo (2023).

Duración Promedio y Mediana

Duración Promedio = AVERAGE(Accidents[Duracion_Min])
Duración Mediana = MEDIAN(Accidents[Duracion_Min])

Contrasta la media afectada por cierres viales extremos (444 min) frente al valor típico central (75 min).

Var MoM %

Var MoM % =
DIVIDE(
    [Total Accidentes] - [Accidentes Mes Anterior],
    [Accidentes Mes Anterior],
    0
)

Mide el crecimiento porcentual mes contra mes usando DATEADD(..., -1, MONTH).

Tasa x 100k Habitantes (Demográfica)

Tasa x 100k Hab =
DIVIDE(
    [Total Accidentes] * 100000,
    MAX(Dim_Demografia[Population_2023]),
    0
)

Normaliza la carga accidental de cada estado respecto a su población oficial según el Censo de EE.UU.

Pipeline ETL en Power Query (Lenguaje M)

Código fuente completo disponible en powerbi/power_query_etl.pq. 

let
    OrigenRaw = Csv.Document(File.Contents("data\US_Accidents_March23.csv"),
        [Delimiter=",", Columns=46, Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    Encabezados = Table.PromoteHeaders(OrigenRaw, [PromoteAllScalars=true]),
    TiposCambiados = Table.TransformColumnTypes(Encabezados, {
        {"ID", type text}, {"Severity", Int64.Type}, {"Start_Time", type datetime},
        {"End_Time", type datetime}, {"Start_Lat", type number}, {"Start_Lng", type number},
        {"State", type text}, {"City", type text}, {"Weather_Condition", type text}
    }, "en-US"),
    ConDuracionMin = Table.AddColumn(TiposCambiados, "Duracion_Min",
        each Duration.TotalMinutes([End_Time] - [Start_Time]), type number),
    ConClimaGrupo = Table.AddColumn(ConDuracionMin, "Clima_Grupo", each
        let w = Text.Lower(Text.Trim(if [Weather_Condition] = null then "" else [Weather_Condition]))
        in if Text.Contains(w, "snow") or Text.Contains(w, "ice") then "Nieve/Hielo"
           else if Text.Contains(w, "rain") or Text.Contains(w, "thunder") then "Lluvia"
           else if Text.Contains(w, "fog") or Text.Contains(w, "haze") then "Niebla"
           else if Text.Contains(w, "cloud") or Text.Contains(w, "overcast") then "Nublado"
           else if Text.Contains(w, "clear") or Text.Contains(w, "fair") then "Despejado"
           else "Otro", type text)
in
    ConClimaGrupo
